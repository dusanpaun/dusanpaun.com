# Linux Troubleshooting: My Favorite Commands

When something breaks on Linux, these commands are my go-to tools:

- `top` or `htop` – check system resource usage.
- `journalctl -xe` – view recent system logs.
- `netstat -tulnp` – see open ports and listening services.
- `lsof -i` – list open files and network connections.
- `df -h` and `du -sh *` – check disk usage.

Mastering these will make you a faster troubleshooter!
